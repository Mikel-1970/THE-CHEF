# THE-CHEF

PWA privada de recetas inteligentes.

## Versión actual
V0.3 — prototipo móvil sin Supabase ni OpenAI.

## Probar en iPhone
La aplicación se publica automáticamente con GitHub Actions en GitHub Pages. Una vez activado Pages con **GitHub Actions** como fuente, abre la URL en Safari y usa **Compartir → Añadir a pantalla de inicio**.

El archivo `THE-CHEF-v0.3-source.zip` contiene el código fuente completo utilizado para la compilación de esta versión.

Diseño seleccionado: marfil cálido, verde oliva y acentos mostaza.
