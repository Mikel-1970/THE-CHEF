# Compartir recetas en redes

La ficha ofrece Compartir PDF (exportador sin cambios) y Compartir en redes.

La tarjeta PNG se compone en el navegador a partir de la fotografía ya visible: publicación 1080 × 1350 o historia 1080 × 1920. Incluye marca, título, tiempo y comensales/copas. No genera otra imagen ni consume IA; tampoco sube la receta a un servicio público.

El archivo se prepara antes de pulsar Compartir imagen para mantener la activación de usuario que exige Web Share. Se comprueba canShare para archivos. La cancelación es silenciosa; si el dispositivo no comparte archivos, se descarga la imagen. Un error permite descargar manualmente. El texto y enlace también se pueden copiar, porque algunas redes no conservan el texto adjunto.

El enlace se construye con el origen y ruta de la app: en esta candidata apunta a la preview. No se enlazan IDs de recetas personales, que no existen en otros dispositivos. No se inventan perfiles sociales ni se promete compatibilidad con una red específica. La publicación final la confirma el usuario en la aplicación de destino.

Validación local: PNG real y dimensiones, compartición nativa simulada con activación de usuario, cancelación, fallo, descarga y copia, en escritorio y móvil. La selección real de Instagram/Facebook/TikTok requiere comprobar esos móviles con las aplicaciones instaladas.

Referencia: https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share
