## Regla de avance
No añadir nuevas funciones antes de F2.6 salvo que sean necesarias para:
1. recuperar una función aprobada que se perdió;
2. corregir un fallo crítico;
3. cumplir una decisión ya aprobada;
4. hacer reproducible la beta privada.

## Línea paralela — Naming
The Chef sigue siendo nombre provisional. El estudio de marca continúa separado del desarrollo. El cambio de nombre se hará una sola vez cuando exista una decisión verificada.
