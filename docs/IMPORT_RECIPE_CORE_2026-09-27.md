# Importador inteligente y Recipe Core — 27/09/2026

## Baseline aprobada
The Chef convierte una fuente culinaria en una receta estándar y lista para cocinar. Todos los orígenes deben terminar en el mismo tipo Recipe.

## Entradas P0
- URL pública de web o red social cuando la fuente exponga contenido accesible.
- Texto pegado o transcripción.
- TXT, MD, DOCX y PDF.
- Foto o captura: se deriva a Foto Receta existente; no se duplica la función visual.
- Creación y generación existentes continúan usando el Recipe Core común.

## Trazabilidad
Cada importación conserva plataforma, URL, creador cuando se conoce, título original y fecha. Los campos pueden registrar evidencia SOURCE, INTERPRETED, ESTIMATED o USER-CONFIRMED. Los datos interpretados o estimados requieren revisión.

## Preferencias globales
- Comensales habituales ya existentes.
- Alergias e intolerancias.
- Ingredientes a evitar.
- Sistema métrico por defecto o mantener originales.
- Nutrición por ración, receta completa o por 100 g cuando exista dato fiable.

## Seguridad y fiabilidad
The Chef no inventa datos ausentes para completar una importación. Las advertencias de alérgenos son orientativas y no certifican seguridad frente a alergias o contaminación cruzada. Las conversiones imperiales se limitan a equivalencias seguras y conservan el valor original.

## Redes sociales
Instagram, TikTok, YouTube y Facebook pueden restringir la lectura automatizada. Si no exponen suficiente información pública, la app pide descripción, texto o transcripción. La PWA de iPhone no instala una extensión nativa de compartir; el flujo P0 usa copiar y pegar el enlace.

## P1 / P2
P1: colecciones, detección de duplicados, sustituciones inteligentes y cola visible de importaciones.
P2: análisis audiovisual profundo, versionado avanzado e importaciones múltiples.
